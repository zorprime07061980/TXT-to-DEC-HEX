Python конвертор кода текстового карт доступа СКУД в шестнадцатеричный и десятичный  например  037,01594    в  25063A   и 0002426426, 
на вход текстовый файл "input_cards.txt" с кодами текстового вида, результат записывает в другой файл output_cards.csv, в нем  в столбиках текстовый,  шестнадцатеричный и десятичный варианты
Разделены столбики точкой с запятой ; для импорта в Excel.
В коде перед десятичным номером (dec_res) добавлен одиночный апостроф (').
• Зачем это нужно: Excel по умолчанию считает длинные числа обычными цифрами и автоматически удаляет ведущие нули (превращая 0002426426 в 2426426).
• Апостроф заставляет Excel принудительно воспринимать эту ячейку как текстовую, бережно сохраняя все нули для СКУД. Сам апостроф при этом на экране виден не будет.
